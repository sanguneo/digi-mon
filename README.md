# digi-mon

> 2022 개정 초등 교육과정을 위한 재현 가능한 학습 문제 엔진

digi-mon은 초등 **국어·영어·수학** 성취기준을 바탕으로 문제, 학습 목표,
단계별 도움말과 채점 근거를 만드는 엔진이다. 같은 교육과정 자료, 옵션,
시드에서는 언제나 같은 문항과 같은 지문값을 만든다.

이 프로젝트의 목표는 완성된 학습 앱이나 인쇄물을 만드는 것이 아니다.
문제 발급, 채점, 학습지원 자료와 다음 학습 행동 제안을 신뢰할 수 있는
기계 계약으로 제공하고, 화면·학습 이력·배정 기능을 담당하는 별도
학습 클라이언트가 그 위에 연결될 수 있도록 하는 것이 목표다.

> 한마디로, digi-mon은 학습 화면이 아니라 학습 화면이 믿고 사용할 수 있는
> 문제·채점·학습지원 엔진이다.

## 왜 만드는가

문제를 무작위로 만들어 주는 것만으로는 학습 엔진이 되기 어렵다. 학습용
시스템에서는 다음 질문에 답할 수 있어야 한다.

- 어떤 교육과정 성취기준을 연습하는 문제인가?
- 같은 문제를 나중에 정확히 다시 만들 수 있는가?
- 학습자에게 정답이나 교사용 정보가 노출되지 않는가?
- 문제와 함께 학습 목표, 원리, 공식 또는 단계별 도움말을 줄 수 있는가?
- 틀린 답을 실제로 틀렸다고 판정하는가?
- 자동 채점하면 안 되는 수행 과제를 억지로 객관식으로 바꾸지 않는가?
- 근거가 부족할 때 숙달도나 진단 결과를 꾸며내지 않는가?
- 이미 본 문항을 다시 내지 않고도 상태 없는 서버로 운영할 수 있는가?

digi-mon은 이 질문들을 생성기 규칙, 버전이 붙은 자료 구조, 지문값 검증,
뮤테이션 검사와 명시적인 실패 방식으로 다룬다.

## 동작 방식

기본 학습 흐름은 다음과 같다.

1. 클라이언트가 교과, 학년군, 성취기준, 난이도, 연습 방식과 문항 수를
   요청한다.
2. 엔진이 조건에 맞는 문제와 학습 목표를 결정적으로 생성한다.
3. 지원되는 문항에는 원리·규칙과 두 단계 도움말이 함께 제공된다.
4. 클라이언트가 시드, 옵션, 지문값과 문항 출처 정보를 보존한다.
5. 학습자의 답안을 같은 계약으로 재생성하여 채점한다.
6. 명시적인 채점 근거를 학습 게이트에 보내면 다음 연습, 보충 학습,
   진도 진행 또는 사람 검토 제안을 받는다.

엔진은 이 과정에서 학습자 세션이나 장기 학습 이력을 저장하지 않는다.
도움말을 언제 공개할지, 어떤 화면을 보여 줄지, 제안을 실제로 실행할지는
클라이언트가 결정한다.

## 핵심 기능

### 교육과정에 연결된 문제 생성

- 2022 개정 초등 국어·영어·수학 성취기준을 사용한다.
- 성취기준 연결 여부와 실제 평가 주제 연결 여부를 구분한다.
- 자동 채점이 부적절한 작도·태도·수행 기준은 별도로 표시한다.
- 지문·음성·매체처럼 아직 조달되지 않은 자료 요구도 숨기지 않는다.

기준 코퍼스는 저장소 안의 `data/spine/standards.json`과 교육부 고시
국어·수학·영어 별책 Markdown으로 고정한다. 현재 검증 대상은 성취기준 248개와
생성기 193개다.

### 독립 실행

- 다른 저장소를 설치하거나 같은 상위 디렉터리에 둘 필요가 없다.
- CI, 시험, 전체 검증, 명령줄 도구와 HTTP 서버가 이 저장소만 사용한다.
- 내부 스파인과 세 공식 별책의 SHA-256이 고정 계약과 다르면 즉시 실패한다.
- 내부 스파인의 248개 성취기준 코드를 공식 별책의 코드 목록과 직접 대조한다.
- 문제 생성과 채점 중 외부 네트워크나 대규모 언어 모델을 호출하지 않는다.

내부 스파인의 최초 버전에 남은 역사적 데이터 계보와 공개 전 권리 검토 사항은
`PROVENANCE.md`와 `NOTICE.md`에 투명하게 기록한다. 실행 독립성과 출처 기록은
서로 바꾸어 쓰지 않는다.

### 재현 가능한 발급

- 같은 온톨로지, 옵션, 시드는 같은 학습지와 같은 `fingerprint`를 만든다.
- 문항, 옵션, 학습지원 내용 또는 자료 말뭉치가 바뀌면 지문값도 바뀐다.
- 발급 당시 조건과 다른 조건으로 채점을 요청하면 실패한다.
- 고유 문항이 부족할 때 중복이나 낮은 품질 문항으로 채우지 않고 명시적으로
  실패한다.

### 반복 노출 방지

클라이언트는 학습자에게 이미 보여 준 12자리 `item.id`를
`excludeItemIds`로 보낼 수 있다. 엔진은 세션을 저장하지 않으면서 해당 문항을
단일 학습지와 모든 병렬 문제지에서 제외한다.

제외 목록도 지문값 계산에 포함되므로, 나중에 채점할 때 같은 목록을 보내야 한다.
외부 제외에는 공개된 문항 식별자를 사용하지만 내부 중복 판정에는 전체
`dedupeKey`를 사용한다.

### 병렬 문제지

같은 평가 조건을 유지하면서 문항이 겹치지 않는 2~8개의 A/B/C형 문제지를
만들 수 있다.

- 모든 형은 같은 성취기준·생성기·난이도 설계를 공유한다.
- 전체 형에서 같은 문항이 다시 나오지 않는다.
- 각 형의 출처 정보로 어떤 형이든 재생성하고 채점할 수 있다.
- 학습자용과 교사용 결과를 분리한다.

### 학습지원 자료

모든 문항에는 학습 목표가 있다. 검토 후보로 작성된 생성기에는 다음 자료도
포함된다.

- 학습할 원리·규칙·전략
- 첫 번째 도움말
- 더 구체적인 두 번째 도움말
- 교사용 관찰점과 개입 제안

학습자용 결과에서는 교사용 정보, 정답과 전체 풀이가 제거된다. 학습지원 자료가
없는 생성기는 없는 도움말을 꾸며내지 않고 `objective-only`로 표시한다.

현재 사고력 연습 6종과 문해 기초 연습 12종이
`guided-candidate` 자료를 제공한다. 이 표시는 저장소에서 작성한 검토 후보라는
뜻이며, 외부 교과 전문가의 승인을 받았다는 뜻은 아니다.

### 세 가지 연습 방식

| 방식 | 보장하는 동작 | 뜻하지 않는 것 |
|---|---|---|
| `advanced` | 생성기가 선언한 난이도 3 문항만 선택 | 영재 판별, 상위권 판정, 숙달 진단 |
| `thinking-skills-v1` | 검토된 규칙·순서·근거 과제 6종만 선택 | 일반 사고력 점수, 창의성, 전이 능력 |
| `literacy-foundations` | 검토된 문자·문장 부호 기초 과제 12종만 선택 | 읽기 수준, 결손, 독해 진단 |

여러 방식을 함께 요청하면 모든 조건을 동시에 만족하는 생성기만 사용한다.
조건에 맞는 문제가 없을 때 일반 문제로 몰래 대체하지 않는다.

### 채점

- 자동 채점 문항은 정규화한 학습자 답안을 정답 계약과 비교한다.
- 작도·수행 문항은 교사가 평가 기준별 참·거짓 결과를 입력한다.
- 답하지 않은 자동 채점 문항도 완료율과 정확도 계산에서 숨기지 않는다.
- 학습자용 채점 결과에는 제출 원문과 정답 피드백을 기본적으로 노출하지 않는다.
- 누적 표본이 부족하면 정확도 집계값을 `null`로 남긴다.

### 무상태 학습 게이트

학습 게이트는 단일 채점 결과나 클라이언트가 보존한 누적 응답 기록을 받아
다음 행동을 제안한다.

- `practice`: 같은 범위를 더 연습
- `remediate`: 승인된 보충 경로로 연습
- `advance`: 클라이언트가 명시한 다음 범위로 진행
- `await-manual-review`: 사람의 평가가 끝날 때까지 대기

결과에는 정책 개정 번호, 판단 이유 코드, 비식별 근거 요약과 다음 행동이
포함된다. 누적 응답은 성취기준별 30개 미만이면 근거 부족으로 남긴다.

이 결과는 숙달도 판정, 심리 진단, 읽기 수준 진단 또는 학습자 예측이 아니다.

## 프로젝트가 맡지 않는 일

digi-mon은 엔진의 책임을 작게 유지한다. 다음 기능은 별도 클라이언트나 운영
시스템의 책임이다.

- 웹·앱 화면과 사용자 경험
- 인쇄물 편집과 출력
- 계정, 학급 명단과 로그인
- 장기 학습 이력과 세션 저장
- 문제 배정과 일정 관리
- 도움말 공개 시점과 학습 흐름 제어
- 교사의 최종 판단과 개입 실행
- 실시간 대전이나 게임 기능
- 학습자 요청 시 대규모 언어 모델, 이미지 또는 음성 생성

따라서 이 저장소만 실행하면 완성된 학습 서비스가 나타나는 것은 아니다.
대신 별도 학습 게이트 클라이언트와 교사용 도구가 사용할 수 있는 안정적인
문제 엔진을 제공한다.

## 빠른 시작

### 요구 사항

- Node.js 20 이상
- 권장 버전: Node.js 24

별도 교육과정 저장소, 데이터베이스나 외부 서비스는 필요하지 않다.

### 설치와 전체 검증

```bash
npm ci
npm test
npm run verify
```

- `npm test`: 자동화된 동작·계약 시험 실행
- `npm run verify`: 생성기, 오답 검출, 어휘, 난이도, 선수 관계, 자산 요구,
  자료 구조와 검토 산출물 전체 검사

### 명령줄에서 문제 만들기

```bash
node bin/worksheet.mjs --help

node bin/worksheet.mjs \
  --subject math \
  --grade 3-4 \
  --count 10 \
  --seed class-a
```

사고력 연습 문제:

```bash
node bin/worksheet.mjs \
  --subject math \
  --grade 1-2 \
  --modes thinking-skills-v1 \
  --count 6 \
  --seed think-a
```

문해 기초 연습 문제:

```bash
node bin/worksheet.mjs \
  --subject korean \
  --grade 1-2 \
  --modes literacy-foundations \
  --count 6 \
  --seed literacy-a
```

서로 겹치지 않는 세 개의 병렬 문제지:

```bash
node bin/worksheet.mjs \
  --subject math \
  --count 10 \
  --forms 3 \
  --seed class-a
```

출력 파일명에는 학습지 지문값 일부가 들어간다. 같은 교과와 시드를 사용해도
옵션이 다르면 기존 파일을 덮어쓰지 않는다.

## HTTP 서버

교사용 정답과 상세 채점 결과를 보호할 비밀값을 지정해 서버를 시작한다.

```bash
TEACHER_TOKEN='replace-with-a-secret' npm run serve
```

기본 주소는 `http://127.0.0.1:8787`이다. 외부에 공개해야 할 때만 `HOST`를
명시한다.

### 주요 경로

| 요청 | 경로 | 설명 |
|---|---|---|
| `GET` | `/health` | 서버 상태 확인 |
| `GET` | `/v1/subjects` | 지원 교과 조회 |
| `GET` | `/v1/standards` | 성취기준 조회 |
| `POST` | `/v1/items` | 특정 성취기준의 개별 문항 발급 |
| `POST` | `/v1/worksheets` | 학습지 발급 |
| `POST` | `/v1/worksheet-forms` | 2~8개 병렬 문제지 발급 |
| `POST` | `/v1/grade` | 지문값을 확인하고 답안 채점 |
| `POST` | `/v1/learning-gate` | 채점 근거에 따른 다음 행동 제안 |
| `GET` | `/v1/prerequisites` | 승인된 선수 관계 조회 |
| `POST` | `/v1/remediation` | 승인된 선수 관계 기반 보충 문제 발급 |

정답이 포함된 발급이나 상세 채점 결과는 다음 인증이 필요하다.

```text
Authorization: Bearer <TEACHER_TOKEN>
```

서버는 이름과 이메일 대신 128자 이하의 가명 학습자 토큰만 허용하며, 전달받은
응답 기록을 저장하지 않는다.

## 자료 계약과 버전

엔진이 만드는 주요 자료에는 독립적인 버전이 붙는다.

| 자료 | 현재 계약 |
|---|---|
| 문항 | `digi-mon/item@2` |
| 학습지원 | `digi-mon/learning-support@1` |
| 학습지 | `digi-mon/worksheet@5` |
| 병렬 문제지 묶음 | `digi-mon/worksheet-form-set@4` |
| 학습 게이트 요청 | `digi-mon/learning-gate-request@1` |
| 학습 게이트 추천 | `digi-mon/learning-gate-recommendation@1` |

정확한 기계 계약은 `schema/`의 자료 구조 정의가 기준이다. 계약이 바뀌면 자료
버전, 시험과 문서를 함께 갱신한다.

## 품질 검증

`npm run verify`는 현재 다음 항목을 포함한 전체 검증 사슬을 실행한다.

- 193개 생성기의 난이도별 대량 표본 생성
- 생성된 정답의 재검산
- 의도적으로 주입한 오답을 놓치는지 확인하는 뮤테이션 검사
- 한국어 표기와 허용 어휘 검사
- 교육과정 연결과 커버리지 자료 구조 검사
- 선수 관계의 순환·역행·누락 검사
- 난이도 차이와 고유 문항 용량 검사
- 그림 문항과 외부 자료 요구 검사
- 사람 검토용 표와 문서의 최신성 검사

최신 수치는 `data/coverage/coverage.json`, `REVIEW.md`와 실제
`npm run verify` 결과를 기준으로 한다.

## 디렉터리 안내

```text
bin/       명령줄 도구와 HTTP 서버

```

## 현재 사람 검토가 필요한 부분

엔진 구현과 기계 검증은 완료되어 있지만, 다음 내용은 자동화만으로 승인할 수
없다.

1. 현재 18개 `guided-candidate` 원리·공식·도움말의 교과 적절성 검토
2. 검토된 학습지원 자료를 다른 생성기로 확장할 범위와 우선순위 결정
3. 사실 표, 난이도 설명과 교육과정 해석의 최종 전문가 확인
4. 외부 지문·음성·매체 자료의 저작권과 사용 승인

사람 검토를 통과하기 전에는 이를 승인된 교육 콘텐츠나 학습자 진단으로
표현하지 않는다.
