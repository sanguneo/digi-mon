# 영어 어휘 출처와 검토 기록

## 결론

제공된 두 단어 자료는 교육부 원자료를 바탕으로 공개되었고 이용에 문제가 없다는
프로젝트 소유자의 확인을 2026-08-06에 받았다. 저장소는 제공된 PDF 자체나 편집
레이아웃을 재배포하지 않고, 공식 교육과정으로 다시 검증한 표제어 데이터만
런타임에 사용한다.

이 판단은 자료의 **이용 가능성**에 관한 것이다. 특정 낱말의 초등 권장 여부와
3~4학년·5~6학년 배정은 별도의 교육과정 판정이다.

## 자료

| 구분 | 저장 위치 | 역할 |
|---|---|---|
| 공식 교육과정 | `reference/[별책14] 영어과 교육과정.md` | `[별표 3]` 판정 기준 |
| 800단어 공개 자료 | 제공된 `교육부 지정 초등필수 영어단어 800.pdf` | 뜻과 수록 목록 |
| 동심공작소 공개 자료 | 제공된 `동심공작소_초등영단어.pdf` | 추가 후보 목록 |
| 병합 목록 | `docs/assets/english-wordlist.md` | 중복 제거한 1,252개 후보 |
| 기계 판독 원장 | `data/curriculum/english-official-vocabulary.json` | 공식 800과 후보 교차 검증 |

공식 고시 안내의 직접 출처는 국가교육과정정보센터의
[2022 개정 초·중등학교 교육과정 고시 안내][ncic-2022]다. 접근·검토일은
2026-08-06이다. 원문과 병합 목록의 SHA-256은 기계 판독 원장의 `sources`에
기록한다.

두 보조 PDF의 공개 게시 URL과 별도 라이선스 문구는 제공 파일만으로 독립 확인하지
못했다. 이 두 파일의 이용 근거는 프로젝트 소유자의 공개 이용 확인이며, PDF 원본은
파생 데이터 배포물에 포함하지 않는다.

## 교육과정 판정

- `[별표 3]` 기본 어휘는 3,000개다.
- 단일 `*` 표제어 800개는 초등학교 사용 권장 어휘다.
- 이 800개는 학년군별 낱말 배정표가 아니다.
- 학습 어휘 한도는 3~4학년군 300개, 5~6학년군 300개다.
- 대표 표제어, 괄호 파생형, 슬래시 대안형과 새 어휘 산정 제외 규칙은
  기계 판독 원장의 `guidelines`에 구조화했다.

병합 후보 1,252개 가운데 공식 초등 표제어와 일치하는 후보 행은 801개다.
`mathematics / maths / math` 한 대표 항목이 `mathematics`와 `math` 두 후보 행에
대응하기 때문이다. 공식 대표 표제어 수는 여전히 정확히 800개다.

## 엔진 사용 상태

현재 엔진은 공식 800개 전체를 임의로 학년군에 나누지 않는다.

| 상태 | 수 |
|---|---:|
| 공식 초등 권장 대표 표제어 | 800 |
| 병합 후보 행 | 1,252 |
| 3~4학년 프로젝트 선택 seed | 30 |
| 5~6학년 신규 프로젝트 선택 seed | 24 |
| 5~6학년 누적 프로젝트 seed | 54 |

`src/curriculum/english-vocab.mjs`의 프로젝트 선택 seed는 공식 원장 포함 여부와
학년군 한도를 테스트로 검증한다. 이 선택은 교과 전문가의 학년 적합성 승인이
아니다. 나머지 후보도 학년군·이해용·표현용 배정을 검토하기 전까지 런타임에서
사용하지 않는다.

기계 원장의 `gradeBandApprovedCount: 0`은 1,252개 후보 행 자체에는 학년군을
배정하지 않았다는 뜻이다. 같은 원장의 `engineGradeBandReview`가 런타임에서
프로젝트가 선택한 seed 30+24개를 별도로 기록한다.
