# 초등 영어 단어 후보 목록 (병합·중복 제거)

교육부 원자료를 바탕으로 공개된 두 자료의 영어 단어를 표제어 기준으로 병합하고
중복을 제거한 후보 목록이다. 두 자료는 공개 이용이 가능한 것으로 검토되었다.

이 문서의 자료 수록 표시는 저작권·이용 허가 또는 특정 학년군 배정을 뜻하지 않는다.
교육과정상 초등 권장 여부는 2022 개정 영어과 교육과정 `[별표 3] 어휘`와 별도로
교차 검증한다.

기계 판독 결과와 이용 검토 기록은
[`english-vocabulary-provenance.md`](english-vocabulary-provenance.md)와
`data/curriculum/english-official-vocabulary.json`에 있다.

## 출처

- **800단어 공개 자료** — `교육부 지정 초등필수 영어단어 800.pdf`
  (교육부 원자료 기반, 스캔 이미지 페이지 판독)
- **동심공작소 공개 자료** — `동심공작소_초등영단어.pdf`
  (교육부 원자료 기반, 텍스트 레이어 추출)
- **교육과정 판정 기준** — 교육부 고시 2022-33호 `[별책 14] 영어과 교육과정`
  `[별표 3] 어휘`의 `*` 표기

## 요약

| 구분 | 수 |
|---|---:|
| 병합 후 고유 표제어 | 1252 |
| ★ 800단어 공개 자료 수록 | 800 |
| 동심공작소 자료에만 수록 | 452 |

## 표기 규칙

- `★` 는 **800단어 공개 자료**에 포함된 표제어다. 교육과정 `[별표 3]`의
  `*` 표기와는 별개의 출처 수록 표시다.
- 뜻은 800단어 공개 자료에 실린 것만 싣는다. 동심공작소 PDF는 한글 뜻 글리프가
  추출되지 않아, 동심 전용 표제어의 뜻은 비워 둔다.
- `a/an`, `act(actual, interact)` 처럼 출처가 병기한 형태는 원문 표기를 살렸다.
