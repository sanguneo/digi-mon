## 이번에 닫은 항목

### 수학

- 저학년 수 한글 쓰기 프록시를 객관식 읽기·인식으로 변경했다.
- `[2수01-04]` 분해·합성을 20 이하로 제한했다.
- `[2수01-08]`의 잘못된 어림셈을 세 수의 정확한 덧셈·뺄셈으로 바꿨다.
- 학년군별 생성기의 명시적 범위와 성취기준 코드 오류를 수정했다.
- 과도하게 복잡한 5~6학년 혼합 계산을 최대 두 연산으로 제한했다.
- 공식 문구로 정당화할 수 없는 프록시 생성기는 비활성화했다.
- 새로 드러난 공백 가운데 `[4수03-03]`, `[4수03-05]`, `[4수03-22]`,
  `[4수04-02]`, `[6수03-04]`, `[6수03-06]`, `[6수03-10]`, `[6수03-15]`는
  결정적 생성기로 구현했다.
- `[4수03-07]` 컴퍼스 작도와 `[4수03-12]` 도형 만들기는 실제 산출물·교사
  루브릭이 필요한 수행으로 자산 요구 원장에 남겼다.

검토된 수학 생성기 집합은 생성기 계약과 전체 수학 생성기 소스 파일을 정규화한
SHA-256으로 고정한다. 현재 승인 집합은 152개이며, 생성기 계약이나 소스 파일이
추가·삭제·변경되면 승인이 fail-closed로 해제된다.

### 영어 어휘

- `[별표 3]`의 단일 `*` 표제어 800개를 결정적으로 추출했다.
- 병합 후보 1,252개와 공식 표제어를 교차 검증했다.
- 런타임 seed에서 직접 대표 표제어가 아닌 `kite`, `van`을 제거하고,
  `teach`의 파생형으로 포괄되는 `teacher`는 대표 표제어 `teach`로 정규화했다.
- 공식 목록과 학년군 한도를 검증하는 freshness 게이트를 `npm run verify`에 넣었다.

### 의미 정렬

이번에 전수 대조한 수학 생성기만 단일 `assesses` 주제에 승인 정렬했다.
승인 의미 커버리지는 119/248이다. 여러 평가 주제를 가진 기준은 특정 주제를
추측하지 않고 후보로 남긴다. 국어·영어도 이번 변경에서 일괄 승인하지 않았다.

### 수행평가

교사가 수동 문항의 기존 루브릭 항목마다 충족 여부를 제출할 수 있다.
자유 서술과 개인정보 필드는 받지 않으며, 루브릭 길이·수동 문항 여부·교사 인증을
검증한다. 결과에는 자동 채점 정확도와 분리된 수동 기준 충족 비율을 제공한다.

## 남은 차단

다음 항목은 현재 저장소의 텍스트와 코드만으로 정직하게 완료할 수 없다.

- 국어·영어 듣기 평가용 음성, 대본과 음질·접근성 검수
- 읽기 이해용 원문 지문과 정답 근거 구간
- 매체 문식성용 화면·광고·정보 탐색 자산과 대체 텍스트
- 말하기·협력·태도·과정 관찰의 실제 교사 증거
- 공식 800개 가운데 나머지 단어의 학년군·이해용·표현용 전문가 배정
- 다중 `assesses` 주제 생성기의 주제별 평가 구인 승인

이 항목은 객관식 프록시나 LLM 추정으로 커버리지에 포함하지 않는다.
