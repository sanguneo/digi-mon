# 국영수 학습과 성장 콘텐츠 확장 방향

## 학습 구성

한 번에 적은 문제만 풀도록 제한하지 않는다. 단순 연산은 충분히 반복하고,
문장이 길거나 여러 단계를 생각해야 하는 문제는 짧게 묶어 제시한다.
문항 수는 학습자가 선택하고, 화면의 묶음과 실제 발급 문항 수를 구분한다.
인쇄할 때는 선택한 학습지의 모든 문제와 선택지를 보존한다.

| 학년군 | 수학 | 국어 | 영어 |
|---|---|---|---|
| 저학년 1~2 | 수 세기·모으기와 가르기·덧셈과 뺄셈 반복, 합치기·남은 수·차이·빈자리의 생활 문제 | 띄어 읽기, 사건과 인물의 마음 연결, 상황에 맞는 표현 | 공식 1~2학년 영어 성취기준을 만들지 않는다. 보호자가 기초 영어를 원하면 3~4학년의 쉬운 문자·낱말·짧은 문장 연습을 선택한다 |
| 중학년 3~4 | 곱셈·나눗셈과 자릿값 반복, 생활 속 수량·분배, 분수와 소수의 기초 | 사실과 의견 구분, 절차와 순서, 문장에서 판단의 근거 찾기 | 색·위치·행동을 구분하는 짧은 문장, 질문에 맞는 응답 |
| 고학년 5~6 | 혼합 계산, 분수·소수 연산, 조건과 계산 순서를 살피는 활용 | 비유적 표현, 주장과 이유, 상황·대화의 단서로 추론 | 소개·묘사, 구체적인 정보 묻고 답하기, 문맥에 맞는 문장 완성 |

### 같은 계산도 다르게 생각하게 하기

- 덧셈: 두 무리를 합치기, 나중에 더 들어오기, 전체와 한 부분으로 빈자리 찾기.
- 뺄셈: 가져간 뒤 남은 양, 두 무리의 차이, 전체에서 다른 부분 찾기.
- 중학년: 묶음의 수와 한 묶음의 수를 구별하고, 나눈 결과의 단위를 확인하기.
- 고학년: 계산 순서나 같은 크기의 단위가 필요한 이유를 설명하며 계산하기.

이름과 물건만 바뀌는 문제에 머물지 않고, 무엇이 주어지고 무엇을 묻는지가
바뀌도록 한다. 같은 시드와 조건에서 재현되는 성질과 정답 검산은 유지한다.
긴 지문을 늘리는 대신 문제를 푸는 데 필요한 상황과 관계를 구체적으로 쓴다.

## 원리 도움말

도움말은 엔진이 제공한 학습지원 자료를 사용한다. 클라이언트가 문제의 답이나
교육과정 설명을 임의로 만들어 내지 않는다.

1. 처음에는 도움말을 접어 두어 스스로 생각할 여지를 남긴다.
2. 열면 이 문제의 학습 목표와 원리·규칙·전략을 보여 준다.
3. 첫 도움말은 개념을 떠올리게 하고, 두 번째는 구체적인 풀이 전략을 제안한다.
4. 도움말을 열었다는 이유로 점수나 키우기 보상을 줄이지 않는다.

예를 들어 덧셈에서는 두 무리를 하나로 모으는 뜻을, 뺄셈에서는 남은 양과
차이를 비교하는 뜻을 설명한다. 현재 문제의 정답 숫자를 도움말에 넣지 않는다.
학습 목표만 있는 문제에는 없는 도움말을 꾸며 붙이지 않는다.
저장소가 작성한 자료의 `guided-candidate` 표시는 교과 전문가의 승인과 다르다.

검사한다. 이는 자동 검증 범위이며 교실에서의 효과를 입증하는 시험은 아니다.

## 과목별 3D 성장 경험

| 과목 | 성장의 중심 | 돌보기와 꾸미기 | 학습과 연결할 소재 |
|---|---|---|---|
| 국어 | 작은 싹에서 잎·꽃·나무로 변하는 정원 | 물 주기, 꽃과 나무 살피기, 획득한 장식 배치 | 변화의 순서, 모습과 느낌을 나타내는 말, 관찰과 의견 |
| 영어 | 작은 물고기가 자라는 어항 | 먹이 주기, 어항 돌보기, 수초와 장식 배치 | 색, 수, 위치, 행동, 짧은 묘사와 질문 |
| 수학 | 몸집과 놀이가 달라지는 강아지 | 먹이 주기, 빗질, 놀이, 생활 공간 꾸미기 | 묶음과 수량, 합치기와 비교, 공평한 분배 |

성장은 해당 과목의 학습 참여와 돌봄을 연결한다. 돌보기 버튼을 반복해서 누르는
것만으로 모든 성장을 끝내는 구조는 피한다. 현재 단계와 다음 변화에 필요한
활동을 함께 보여 주고, 달성한 단계는 성장 기록으로 다시 볼 수 있게 한다.
성장은 크기뿐 아니라 잎·꽃, 물고기의 모습, 강아지의 행동처럼 알아볼 수 있는
변화로 표현한다.

오답, 결석, 오래 접속하지 않은 것 때문에 시들거나 배고파지거나 성장이
되돌아가지는 않는다. 시간 제한, 연속 접속 압박, 순위 경쟁을 도입하지 않는다.
배우고 돌본 경험과 장식은 이 브라우저에 저장하고, 다른 과목의 진행도와 섞지 않는다.

## 모바일·태블릿 우선 사용

휴대폰과 패드를 PC보다 자주 사용하는 상황을 기준으로 삼는다.
세로 화면뿐 아니라 태블릿 가로 화면에서도 문제와 3D 공간을 이용할 수 있어야 한다.

- 터치 표적은 최소 48px로 확보하고, 작은 드래그 지점이나 마우스 올리기에 의존하지 않는다.
- 입력 글자는 16px 이상으로 유지하며, 분수·한글 답안에 필요한 키보드를 제한하지 않는다.
- 많은 문제는 묶음 바로가기로 이동하되 이동하거나 키우기 화면을 다녀와도 답안을 지우지 않는다.
- 3D 공간의 기본 터치 동작은 페이지 스크롤을 막지 않는다. 회전은 명시적인 조작으로 전환한다.
- 움직임 줄이기 설정을 존중하고, 화면 밖이나 백그라운드에서 불필요한 렌더링을 멈춘다.
- WebGL을 사용할 수 없을 때도 현재 성장과 돌봄·배치 상태를 텍스트와 버튼으로 이용한다.
- 브라우저 모사와 실제 기기 검증을 구분한다. 운영체제의 화면 키보드와 Safari 실기기 동작은
  데스크톱의 모바일 크기 검사만으로 검증했다고 주장하지 않는다.

## 콘텐츠를 더 붙일 때의 적용 기준

- 학년군과 성취기준을 먼저 정하고, 읽기 부담과 필요한 계산 단계를 따로 확인한다.
- 새 상황마다 정답이 하나인지, 오답 선택지가 다른 해석으로 정답이 되지 않는지 확인한다.
- 문항 수를 늘릴 때 고유 문제의 용량을 검사하고, 부족한 문제를 중복으로 채우지 않는다.
- 원리·힌트·정답·교사용 관찰 자료의 공개 경계를 유지한다.
- 생성과 검산 시험 외에도 실제 학습지의 선택지·그림·인쇄·모바일 표시를 확인한다.
- 3D 보상은 교육과정의 성취 판정이 아니다. 학습자의 능력이나 성격을 판단하지 않는다.
